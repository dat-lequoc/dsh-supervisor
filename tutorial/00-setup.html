Before Part I — Required setup

Start on a clean PC

This is the only supported starting state for the course: no running Harness, no Harness source checkout, no main-agent preset, and no supervisor plugin. Finish every check on this page before chapter 1.

How this course app starts

You have already cloned dsh-supervisor to reach this page. From that clone, the one local setup command creates an isolated Python environment, installs only the grader's PyYAML and zstd decoder dependencies, chooses an unused localhost port, and serves the tutorial with working grade buttons: 

cd "$HOME/src/dsh-supervisor"
./tutorial/setup.sh

Keep that terminal open and use the URL it prints. The script deliberately does not install dsh, clone DeepSeek Harness, configure a model, or create your lab; those learning steps remain visible below. Press Ctrl-C when you want to stop the course server.

Supported shell and prerequisites

The commands use a POSIX shell on Linux or macOS. On Windows, run them inside WSL. The course launcher needs Python 3; on Debian/Ubuntu it automatically installs missing python3-venv support through apt-get. For the Harness itself, install Git, Node.js 22.19+ in the Node 22 line or Node 24+, and the tools below. Node 23 is not a supported Harness runtime. Use an LTS installer from nodejs.org; on Ubuntu/WSL the remaining packages are: 

sudo apt update
sudo apt install -y git python3

On macOS, install Git and Python 3 with Homebrew or your preferred package manager. The setup script already installs the Python grading libraries inside the repository, so it does not modify your system Python. Finally verify the Harness prerequisites:

git --version
node --version       # v22.19+ in 22.x, or v24+
npm --version
python3 --version
test -x "$HOME/src/dsh-supervisor/tutorial/.venv/bin/python"

Install DeepSeek Harness

npm install --global @deepseek-ai/dsh
dsh --version

The npm installation is the runtime. The source checkout in the next step is for the course's cited code tours; do not modify it.

Clone DeepSeek Harness beside this course

The course repository is already at $HOME/src/dsh-supervisor. Clone the Harness source beside it for the cited code tours. The global npm package remains the runtime; do not modify this source checkout. 

mkdir -p "$HOME/src"
git clone https://github.com/deepseek-ai/deepseek-harness.git \
  "$HOME/src/deepseek-harness"

test -f "$HOME/src/dsh-supervisor/package.json"
test -f "$HOME/src/deepseek-harness/docs/architecture.md"
Do not install the supervisor bundle yet

Chapter 6 installs this repository as a profile bundle before any dsh-supervisor/… row is mounted. At the next boot, the bundle installs the matching packaged main-agent preset. Keeping package and preset installation together prevents rows from referring to package names that do not exist yet.

Start dsh and configure one model

Run the server in a terminal and leave that terminal open:

dsh web

Open http://127.0.0.1:3080, then go to Settings → Models and configure a working provider/model route. The tutorial cannot test prompts until a model succeeds. A terminal multiplexer is optional; no chapter assumes one.

Create the lab workspace

mkdir -p "$HOME/agi-lab/.agi/subagents"
cp "$HOME/src/dsh-supervisor/agi-template/config.json" \
  "$HOME/agi-lab/.agi/config.json"
touch "$HOME/agi-lab/.agi/NOTES.md" \
      "$HOME/agi-lab/.agi/progress.jsonl" \
      "$HOME/agi-lab/.agi/questions.jsonl" \
      "$HOME/agi-lab/.agi/CHANGELOG.jsonl"
Setup gate — do not continue until all six pass
  1. node --version is 22.19+ in the 22.x line, or 24+; the course server's setup check passes below.
  2. dsh --version succeeds.
  3. The course and Harness repositories both exist under $HOME/src/.
  4. http://127.0.0.1:3080 loads.
  5. A simple prompt in a standard session receives a model response.
  6. $HOME/agi-lab/.agi/config.json exists and $HOME/.dsh/profiles/web/package.json was created.
